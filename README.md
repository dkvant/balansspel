# Balansspel

Mobilspel där du balanserar en kula från A till B genom att luta telefonen.

## Starta

```bash
bun install   # eller npm install
bun start     # eller npm start
# Tunnel: bun run tunnel
```

Öppna i Expo Go och skanna QR-koden.

## Features

- Accelerometer-styrning
- 14 banor, 5 världar
- Power-ups, skins, achievements
- Monster AI, daily challenges, statistik, tutorial
- Skia-grafik + partikeleffekter

## Stack

Expo SDK 57 · React Native · Skia · React Navigation
